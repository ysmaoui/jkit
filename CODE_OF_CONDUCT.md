# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Summary

- Be respectful. Assume good intent. Disagree on substance, not on people.
- No harassment, personal attacks, or discriminatory language.
- Maintainers may remove comments, commits, or contributors that violate these norms.

## Reporting

Report unacceptable behavior to the maintainer at the email on the GitHub
profile, or via a GitHub private vulnerability report. Reports are kept
confidential.
